# Cryptography Lab with SageMath

A mathematics and cryptography laboratory built with SageMath.

## Objectives

This project explores the mathematical foundations of cryptography
and implements cryptographic algorithms using SageMath.

Topics include:

- Number theory
- Modular arithmetic
- Finite fields
- Classical cryptography
- RSA
- Diffie-Hellman
- ElGamal
- Elliptic curves
- Elliptic Curve Cryptography (ECC)

## Goals

- Strengthen mathematical foundations for cryptography
- Implement cryptographic algorithms from scratch
- Explore the mathematical problems behind cryptographic security
- Use SageMath for symbolic computation and experimentation
- Document the mathematics behind each implementation
